# クラス支援ツール（試用完成版・v36）

統合仕様書をもとにした、GitHub Pages向けのブラウザアプリです。

## この段階で動く機能

- 同期・バックアップ復旧・クラス削除・年度切替を、途中失敗で一部だけ書き換わらない一括更新へ変更
- 同期直前の状態を暗号化して端末内に最大3件・30日間保存し、設定のデータ管理から戻せるように変更
- 同期ファイルとバックアップは、形式・年度・参照関係・件数・ファイル容量を反映前に検証
- 同期取込は「現在データへ統合」、バックアップ復旧は「現在データを置換」と役割を明示

- 約1,500行の単一JavaScriptを、共通基盤・画面枠・設定・日常記録・席替え・所見／児童詳細・データ管理・起動処理へ分割
- 分割したスクリプトを実際の読込順で個別評価する回帰テストを追加
- v34の機能処理を維持したまま、各機能の修正範囲を判別しやすい構成へ変更
- 更新確認時にv34のキャッシュを残してしまう固定記述を修正し、現在の公開版キャッシュを参照
- index.html、Service Worker、全公開資材をv35へ統一

- 設定トップを「まず使う／ときどき使う／年度始め・端末を替えたとき」の3群に整理
- ヘッダーとクラス選択で現在のクラスを「操作中」と明示
- ホームの赤い件数を「要対応○人」と表示し、意味をボタン内で確認可能
- 標準アイコンを「宿・週・賞・メ・B・提・席・所・学」の意味が分かる文字へ変更
- データ管理は「端末間で記録をまとめる」「故障に備えて保存する」を前面にし、履歴・Excel・復元は折りたたみ
- 提出物の「完結・アーカイブ」を「回収を終える」へ変更
- 支援級の単元画面を「同じ単元を学ぶ児童のまとまり」として案内
- 席替えは配慮設定済み人数と、「配慮なし／設定した配慮を使う」を作成ボタンに表示
- タップ動作は変えず、説明を短文と「押し方を見る」のアコーディオンに整理

- 初回設定後も「児童登録→毎日の宿題→児童用画面」の進み具合を保存し、次の操作を画面内で案内
- 席替えはiPadで2つの座席を順に押して交換でき、交換後も配慮条件の警告を再判定
- 「離す・近く・ペア」は、出席番号の手入力に加えて相手児童を一覧から選択可能
- 同期を「ファイル作成→Teams等で移動→別端末で取込」の3段階で案内
- 個人情報を含まない同期練習用JSONを作成・確認でき、本番データを変更せず受け渡しを試せる
- 週宿題と提出物では現在記録中の対象を共通表示で強調し、児童詳細ボタンの意味を明記

- 初回設定を「クラス」「教師用PIN」「保存データを守る言葉」の3段に分け、学校期間は通常そのままで使える折りたたみ項目に整理
- 初回設定後の主ボタンを「保存して児童登録へ進む」に変更し、次に行う操作を明確化
- 設定トップを「まず確認」「必要なとき」「年度初め・変更時」などの目的別表示に変更
- 設定名称を「クラス・名簿」「年度・ログイン」「メモ・賞状の選択肢」「保存・端末間共有」へ整理
- 名簿の一人ずつ登録は氏名入力欄の横で登録でき、番号・学年・性別の一括変更用保存とは用途を分離
- 名簿がないクラスのホームに、中央の「児童を登録する」案内を表示
- ノート評価は「1回目=B、2回目=評価変更」、ミニ賞状は「1回目=渡した、2回目=理由・取消」を画面内で明示
- 児童用提出画面の教師入口を「⚙ 先生用」と明記

- ノート評価を教科別の傾向・主な単元・評価として集約

- 席替え：クラス名簿・性別を自動利用
- 男女配置、視力、前後・窓側・廊下側、離す・近く・ペアの条件設定

- 新形式バックアップはデータ保護パスワード・緊急復旧コードのどちらでも復号可能
- 教師認証画面の「パスワードを忘れた場合」から暗号化バックアップを選択

- 旧設定の端末では、最初の新形式バックアップ作成時だけ緊急復旧コードを再確認
- 同一端末に残る旧ツールデータの自動検出と一覧確認
- クラスチェッカー、複数クラスチェッカー、席替えメーカー、行動記録CSVの移行
- 旧JSON・CSVバックアップの複数ファイル一括読込
- データ群ごとの移行先年度・クラス選択
- 名簿、宿題、週宿題、賞状、児童メモ、ノート評価、座席・配慮条件、支援級記録の変換
- 同一記録は重複させず、更新日時のない内容違いは両方を残して要確認化

## 総合テスト

```sh
node tests/run-tests.js
```

実際のiPad Safariでのファイル保存・読込と、Teamsを経由した端末間同期は、学校の実機環境でダミーデータを使って最終確認してください。

## 試し方

Webサーバー上で `index.html` を開きます。Service Workerは `file://` では動かないため、GitHub PagesまたはローカルWebサーバーを使用してください。

例：

```sh
python3 -m http.server 8000 --directory class-support-app
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## 配布時の注意

- GitHub Pagesでは、このフォルダー内のファイルを同じ階層へ配置します。
- v36では `app-core.js` から `app-data.js` までの分割ファイルも必要です。ZIPの中身を省略せず、すべて同じ階層へアップロードしてください。
- 更新時は `sw.js` の `CACHE_NAME` を変更します。
- 実際の児童氏名を入れる前に、ダミーデータでiPadとPCの操作を確認してください。
- 実際の児童氏名を扱う前に、専用のダミーデータでiPadとPC間の同期テストを行ってください。
