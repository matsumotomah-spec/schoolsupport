# クラス支援ツール（実装版・第21段階）

統合仕様書をもとにした、GitHub Pages向けのブラウザアプリです。

## この段階で動く機能

- 初回設定（年度、前期・後期、一般級／支援級、自分のクラス、教師用PIN、年度パスワード）
- 日常の教師認証は数字6桁のPIN、暗号化・復号は年度パスワード、緊急復旧は復旧コードに分離
- PINを5回間違えた場合は30秒間入力を停止し、ページ再読込後もロックを維持
- 旧版データは年度パスワードで一度確認し、教師用PINを追加して引継ぎ
- 教師用設定からPINと年度パスワードを個別に変更
- 新しい端末の初回画面から暗号化バックアップを復旧
- アプリ起動時は教師用PIN認証を経て教師ホームを表示
- ヘッダーからライトモード／ダークモードを切替え、端末ごとに設定を保存
- 年度パスワードを「本人には覚えやすく、他人には推測されにくい8文字以上」と案内
- 設定タブから同期・バックアップ画面へ直接移動
- 復旧コードの作成、再入力確認、コピー、TXT保存、印刷
- クラス追加・編集、自分のクラスの先頭固定、クラスカラー変更
- クラスごとの一般級／個別支援級設定
- クラスごとの記録対象教科設定
- 明るいクラス色では黒文字、暗いクラス色では白文字を自動選択
- 名簿の貼り付け、Excel（.xlsx）・CSV・TXT取込、手入力
- Excel名簿は先頭シートを端末内で読み込み、先頭10行から見出しを自動判定
- Excelの列順が異なっても「出席番号・氏名・学年・性別」の見出しから割り当て
- クラス・期間を選んだ提出状況CSVの出力
- 毎日の宿題、週宿題、不定期提出物を提出・未提出・未確認・忘れた・欠席まで一覧化
- 登録した提出回について、記録がない児童も未提出または未確認としてCSVへ出力
- クラス・期間を選んだノート評価一覧CSVの出力
- CSVをExcelで開いた際の文字化けと数式誤認を防ぐ処理
- 4月以降も前年度のままの場合、教師用ホームへ年度切替案内を継続表示
- 前年度のまま記録を始める際に「新年度へ切替／一時継続」を確認
- 児童用提出画面では、年度未切替時の最初の記録前に教師認証を要求
- 新年度切替前に前年度の暗号化保管ファイルを作成
- 保存した保管ファイルを正常に読み直し、現在データとの一致を確認してから切替
- 新年度の年度期間、クラス種別、色、教科、年度パスワードをまとめて設定
- 新年度用の復旧コードを作成し、再入力確認後に切替
- 児童メモタグ、支援級共通タグ、所見プロンプトを選択して新年度へ引継ぎ
- 新年度へ名簿・記録を持ち越さず、確認済みの前年度データをアプリから削除
- 前年度の保管ファイルをアプリへ戻さずに、クラス・児童・記録件数を確認
- 暗号化ファイル表面に、機密情報を含まない年度別パスワードヒントを保存
- 教師用ホーム右上に「同期」と「設定」を並べて配置
- 各教師用機能の右上からも設定画面を開けるように整理
- 独立していた名簿タブを廃止し、「クラス・名簿設定」へ統合
- クラスごとの名簿人数を表示し、各クラスの名簿編集へ直接移動
- 名簿がないクラスで宿題・メモ・評価・提出物・席替え・所見などを開いた場合、そのクラスの名簿設定へ自動移動
- CSV、旧データ変換、画面導線、オフラインキャッシュ対象を確認する自動総合テストを追加
- ノート評価のA・B＋・B・B－・Cを、評価ボタンの幅が揃う配置に調整
- Bは幅を揃えたまま高さと文字を大きく表示
- ホーム・教師用画面から開ける「使い方・FAQ」を追加
- 初回設定、日常操作、端末間同期、表示の見方、年度切替、支援級、パスワード復旧を案内
- よくある質問を折りたたみ式で確認可能
- クラス選択ボタンにクラスカラーを表示し、現在のクラスを視認しやすく改善
- ホームに対応件数バッジの意味を表示
- 教師用ホームに「今日の確認」ダッシュボードを追加
- 同期・バックアップ・年度保管・同期取込の履歴を最大20件保存
- 同期画面で最近の履歴を表示し、端末名・日時・変更件数を確認
- 同期・バックアップ・CSV出力・同期反映の二重クリックを防止
- 各機能ボタンのアイコンを統一したタイル表示に改善
- 名簿項目（出席番号、氏名、学年、性別）
- 名簿から外した児童を日常画面から非表示にし、保存済み記録は維持
- 教師用ホームと児童用「毎日の宿題」画面
- 教師ホームの「毎日の宿題」は教師用画面として開き、認証状態を維持
- 毎日の宿題：1回目「提出」、2回目「忘れた」、3回目「未確認」
- 前回の忘れ物が未解決の児童だけ確認ダイアログを表示
- 前回忘れがある児童を、翌日の画面を開いた時点で赤く表示
- 児童用提出画面から、毎日の宿題・週宿題・不定期提出物を認証なしで切替
- 児童用画面では教師向けの履歴・メモ・管理操作を非表示
- 児童用画面は当日・現在の提出物に固定し、日付移動を非表示
- 教師用の記録画面では日付を「9月6日（日）」形式で上部表示し、左右ボタンで移動
- 週宿題：週の登録、児童ごとの複数週まとめ提出、提出取消、未提出週の強調
- 児童用週宿題：タップごとに「提出・忘れた・未提出」を切替
- ミニ賞状：1回目で配付、2回目で理由タグ・メモ・配付取消
- ミニ賞状の日付移動、全クラス共通タグの教師用設定
- 児童メモ：観点、教科（任意）、自由記述
- 個別支援級では児童メモをホームの最大ボタンとして表示
- 児童メモ：教科選択、プラス評価タグだけでも保存可能、自由記述は任意
- 児童メモの観点選択を撤去
- 児童メモのタグを教師用設定から編集
- 個別支援級では、現在の学期について児童別・教科別の「メモが不足」を表示
- 「メモが不足」の教科ボタンから、該当児童と教科を選択した状態で入力画面を表示
- 児童メモのホームバッジを、不足している児童数と連動
- ノート評価：1回目B、2回目でA・B＋・B・B－・C・欠席・未提出
- ノート評価の教科選択、題名空欄時の日付による自動表示
- 不定期提出物：未提出・提出済み、提出取消、完結・再開
- 各記録画面で児童ごとの最終メモ日を表示
- 児童概要：最新メモ、未解決件数、最後の記録日、機能別タブ
- 記録の詳細表示、児童メモの再編集、30日間のごみ箱
- 「単元設定」で現在の学習単元を教科別に管理
- 現在の学習単元へ児童をドラッグ、またはタップして移動
- 学習記録：児童選択、定型項目、複数タグ、自由記述、続けて次の児童
- 支援級記録件数を「記録なし・かなり少ない・やや少なめ」で表示
- 支援級共通タグを教師用設定から編集
- 所見素材：現在の前期・後期の児童メモ・ノート評価・学習記録を自動選択
- 不要な記録を外して、所見素材テキストとAI用プロンプトを作成
- ノート評価を教科別の傾向・主な単元・評価として集約
- 所見素材とAI用プロンプトのコピー・TXT保存
- 全クラス共通の所見プロンプト設定と推奨設定への復元
- 席替え：クラス名簿・性別を自動利用
- 男女配置、視力、前後・窓側・廊下側、離す・近く・ペアの条件設定
- 男女ペアは1・2列、3・4列、5・6列の組だけを判定し、組をまたぐ同性隣接を許可
- 窓側・廊下側・前方などの位置条件を先に割り当てる配置方式へ改善
- 分散グループの名称変更と任意グループの追加
- グループ分散、リーダー分散、前回と同じ席の抑制
- 自動配置後のドラッグによる座席交換、条件警告
- 席替え履歴の保存・再表示、座席表印刷
- 確定した並びを、別ボタンで日常の児童グリッドへ反映
- 席替えで満たせていない条件を、条件名・児童名付きで個別表示
- ドラッグによる座席交換後も配慮条件を再判定
- 日常の宿題・提出物画面へ列数、行数、空席位置を含む座席形状を反映
- 教師用の毎日の宿題・週宿題・不定期提出物で「座席順／出席番号順」を切替
- 年度パスワードによるAES-GCM暗号化同期・バックアップ
- 今年度の全クラス・名簿・記録・設定を1つの暗号化JSONへ保存
- 同期時は更新日時が新しいデータを採用し、追加・更新・削除候補を事前表示
- 削除候補は詳細画面でまとめて承認した場合だけ反映
- 同期完了後に統合済み同期ファイルを保存
- 同期ファイル名へ日時と作成端末名を自動付与
- 同期・バックアップの開始時だけ年度パスワードを確認し、同じ教師セッション中は再入力を省略
- 1か月ごとのバックアップ案内と「後で」にした場合の7日後再表示
- 新形式バックアップは年度パスワード・復旧コードのどちらでも復号可能
- 教師認証画面の「パスワードを忘れた場合」から暗号化バックアップを選択
- 復旧コードでデータを開いた後、新しい年度パスワードを設定
- 旧形式の暗号化同期・バックアップは年度パスワードで引き続き読込可能
- 旧設定の端末では、最初の新形式バックアップ作成時だけ復旧コードを再確認
- 同一端末に残る旧ツールデータの自動検出と一覧確認
- クラスチェッカー、複数クラスチェッカー、席替えメーカー、行動記録CSVの移行
- 旧JSON・CSVバックアップの複数ファイル一括読込
- データ群ごとの移行先年度・クラス選択
- 名簿、宿題、週宿題、賞状、児童メモ、ノート評価、座席・配慮条件、支援級記録の変換
- 同一記録は重複させず、更新日時のない内容違いは両方を残して要確認化
- 移行後の暗号化バックアップを読み直してから、旧形式データを削除
- 児童画面へ移った時点で教師認証を解除
- 教師ホーム下部の「児童用の提出画面」から移動した場合も即時に認証を解除
- 児童用提出画面から教師ホームへ戻るときだけ教師用PINを要求
- 教師画面は5分無操作で自動ロック
- IndexedDBへの端末内保存
- PWAの基本構成と画面資材のオフラインキャッシュ
- ヘッダーにオンライン／オフライン状態を表示し、通信断時も端末保存で継続できることを案内
- 予期しない保存エラーを画面下部へ通知

## 総合テスト

構文、提出状況CSV、ノート評価CSV、旧データ変換、教師用設定への導線、名簿未登録時の移動、年度切替の保管確認、オフラインキャッシュ対象を確認できます。

```sh
node tests/run-tests.js
```

実際のiPad Safariでのファイル保存・読込と、Teamsを経由した端末間同期は、学校の実機環境でダミーデータを使って最終確認してください。

## 試し方

Webサーバー上で `index.html` を開きます。Service Workerは `file://` では動かないため、GitHub PagesまたはローカルWebサーバーを使用してください。

例：

```sh
python3 -m http.server 8000 --directory class-support-app
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## 配布時の注意

- GitHub Pagesでは、このフォルダー内のファイルを同じ階層へ配置します。
- 更新時は `sw.js` の `CACHE_NAME` を変更します。
- 実際の児童氏名を入れる前に、ダミーデータでiPadとPCの操作を確認してください。
- 実際の児童氏名を扱う前に、専用のダミーデータでiPadとPC間の同期テストを行ってください。
