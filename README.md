# クラス支援ツール（試用完成版・v84）

### v84：設定詳細までカード型に統一

- 表示設定を、説明量・明るさ・児童一覧・児童用画面・アイコンのカードから直接確認できる構成へ整理
- 設定詳細、記録候補、所見、年度、データ操作、名簿を共通のカード表示へ統一
- 名簿に「設定一覧」と「クラス一覧」へ戻る階層を明示
- データと安全の詳細画面を「データの操作」に統一し、旧タブ用スタイルを削除

### v83：設定を4つの統一カードへ再編

- 設定の横タブと「表示・入力」内のサブタブを廃止
- 「クラスと児童」「画面と操作」「記録の候補」「データと安全」の4カテゴリに統一
- 各カテゴリ内も、目的・現在値・操作名を示すカードから開く構成へ変更
- 個別設定には「設定一覧へ戻る」を統一表示し、保存済みの設定値は維持

### v82：表示設定を目的別に案内

- 「児童メモ」と「行動の記録」を「児童の記録」に統合
- 一般級はカテゴリー→児童、個別支援級は児童→メモ・カテゴリーの入力順に最適化
- 担当クラス以外ではノート評価をホームの大きな最優先項目に変更
- ヘルプに目的別ショートカットを追加し、設定の名称を役割ごとに整理
- PIN省略中の職員室PCは、5分無操作でも児童用提出画面へ自動遷移しない

### v74：日常操作の安全性と状態表示

- 教師用の毎日・週宿題の状態変更直後に「取り消す」を表示
- 週宿題の土曜日自動忘れを、実際の「土曜日以降にアプリを開いた時点」の動作に合わせて案内
- 小テストに入力済み・未入力人数を表示し、採点パネル表示中でも名簿が隠れない余白を確保
- 紙テストのExcel取込確認で、観点ごとの得点入力人数を表示
- 教師画面上部に端末保存／最終同期の状態を表示。PC PIN省略の有効化時は確認を追加

### v73：ヘルプ統一と配布構成の整理

- 現行仕様に合わせて毎日の宿題、週宿題、小テスト、紙テスト、行動の記録、PC専用PIN、席替え印刷のFAQを追加・修正
- 古い「提出・忘れた・未確認」表記を現行の教師用状態へ統一
- 配布ZIPから古いUX検証・改修メモ・総合テスト記録を除外し、利用者向けREADMEだけを残す

### v72：Excel紙テストの未実施欄を除外

- Excel内で得点が入力されているテストだけを取り込み候補に表示
- 空欄の未実施テストは候補・登録対象から除外
- プレビューに「得点あり」と「名簿一致」の人数を分けて表示
- 「知・技」「思判表」などの観点列を知識・技能／思考・判断・表現として集計

### v71：週宿題の提出期限表示と自動忘れ

- 週宿題の作成時に、金曜日までの提出期限と次の土曜日の自動「忘れた」を設定可能
- 月〜金の欠席日数が設定基準以上の児童は自動忘れから免除
- 児童用週宿題画面に提出期限と免除条件を表示
- 職員室PCでは教師画面PINを省略できるモードを追加（タッチ端末ではPINを維持）

### v70：行動の記録と通知表用ヒートマップ

- 先生専用の「行動の記録」を追加し、10カテゴリーから選んで座席順または出席番号順で○を記録
- 選択中カテゴリーの一言基準と具体例を常時表示し、思いやり・公共心など迷いやすい区別を補助
- 児童ごと・カテゴリーごとの○件数を、前期・後期・年間・指定期間のヒートマップで確認
- ヒートマップのセルから日付別履歴を開き、誤った○を解除可能
- ○がないことを否定評価に使わず、件数から成績を自動決定しないことを画面上に明記

### v69：小テスト入力と席替え印刷の改善

- 小テスト入力ダイアログを座席表が収まる広幅表示に変更
- 点数選択を画面下の固定パネルにし、児童カードからスクロールせず採点可能に変更
- 席替え印刷では氏名のスペースを姓・名の改行位置として使用
- 長い姓・名は文字数に応じて自動縮小し、文字途中での改行を防止
- 「一部忘れた」は児童用の提出物一覧には警告表示しない

### v68：毎日の宿題の欠席・一部忘れ・表示配慮

- 教師用のカード操作を「提出 → 忘れた → 欠席 → 未確認」に変更
- 児童用のカード操作に「一部忘れた」を追加（提出 → 忘れた → 一部忘れた → 未確認）
- 一部忘れたを月間0.5回として集計し、その月の達成アイコン対象から除外
- 児童詳細の「宿題・提出物」で、児童用一覧と毎日の宿題から個別に状態を隠せる設定を追加
- 詳細編集・今週の確認画面・CSV出力へ「一部忘れた」を反映

### v67：小テストの座席表・高速タッチ入力

- 小テストを100点満点に固定し、満点欄の入力操作を廃止
- 座席順では児童用画面と同じ座席形状・空席を表示し、出席番号順へも切替可能
- 初回タッチで100点、再タッチで100〜0の10点刻み、＋5点、決定を表示
- 0点＋5点で5点、50点＋5点で55点など、5点刻みを少ないボタンで入力可能
- 直接入力では0〜100点の任意の整数を入力可能

### v66：全体監査・画面遷移と入力対象の整合性修正

- 児童用の不定期提出で、複数の提出物を切り替えて記録できるよう修正
- 漢字／計算テストの切替時に入力点をクリアし、教科対象外児童への誤登録を防止
- 過去のテスト点数は実施日時点の在籍者で表示し、転出後も履歴を確認可能に修正
- 学習記録の「保存して次の児童」を、選択教科の記録対象児童だけに限定
- 提出対象外児童を欠席入力でも座席表示だけに統一し、不要な操作を防止
- 未使用関数と不要な変数を除去し、重複・未参照関数がないことを自動検査

### v65：重複コード整理・実際の採点表による取込修正

- 小テスト／紙テスト／教科の絞り込み、交流児童の氏名だけの座席表示を実データ処理に近い自動テストへ強化
- 同名関数の重複定義を検出する回帰テストを追加

### v62：提出表示・週宿題・3観点の成績目安


実際のiPad Safariでのファイル保存・読込と、Teamsを経由した端末間同期は、学校の実機環境でダミーデータを使って最終確認してください。

## 試し方

Webサーバー上で `index.html` を開きます。Service Workerは `file://` では動かないため、GitHub PagesまたはローカルWebサーバーを使用してください。

例：

```sh
python3 -m http.server 8000 --directory class-support-app
```

その後、ブラウザで `http://localhost:8000/` を開きます。

## 配布時の注意

- GitHub Pagesでは、このフォルダー内のファイルを同じ階層へ配置します。
- `app-core.js` から `app-data.js` までの分割ファイルも必要です。ZIPの中身を省略せず、すべて同じ階層へアップロードしてください。
- 更新時は `sw.js` の `CACHE_NAME` を変更します。
- 実際の児童氏名を入れる前に、ダミーデータでiPadとPCの操作を確認してください。
- 実際の児童氏名を扱う前に、専用のダミーデータでiPadとPC間の同期テストを行ってください。
